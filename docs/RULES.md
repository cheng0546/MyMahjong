# 牌规说明(四川麻将"血战到底",好友休闲版)

本文记录**已由房主确认并已实现**的规则。所有数值集中在 `shared/rules.ts` 的 `DEFAULT_RULES`;每局开局时复制为快照保存,牌局中不会改变。
这是"好友休闲默认方案",**不是**所有地区通用的"标准规则"。

## 调研来源

- 《四川麻将竞赛规则》TTFMJ 01-2024: <https://max.book118.com/html/2024/0713/5001141033011243.shtm>
- MJLab 四川麻将规则: <https://mjlab.app/docs/sichuan>
- 四川麻将官方规则站: <https://official-scmahjong.com.cn/rules>

各来源在番型、番数、杠分、查叫细节上有差异,以下为向房主展示推荐值并经确认后的取舍。"炸胡"(错误宣告胡牌受罚)是好友局自定义规则,不来自上述来源。

## 牌组与开局

- 108 张:万、条、筒各 1-9,每种 4 张;无字牌、无花牌。
- 服务器随机分座位、随机首局庄家;庄家 14 张,其余 13 张。
- **换三张**:由庄家选择 顺时针 / 逆时针 / 对家 / 不换;每人选 3 张同花色牌交换。
- **定缺**:每人选一门(万/条/筒)作为缺门,开局前互相不可见。手中还有缺门牌时,必须先打缺门牌。

## 胡牌与番数

- 胡牌形:4 组面子+1 对将,或七对。胡牌时手牌中不得含缺门花色。
- 底分 `baseScore = 1`。每个付分者支付 `1 × 2^番数`。
- **自摸加底**:自摸时每位付分者额外多付 1 底分。
- 番数**不封顶**。

| 番型 | 番 |
|---|---|
| 平胡 | 0 |
| 对对胡 | 1 |
| 七对 | 2 |
| 清一色 | 2 |
| 金钩钓(四组副露、单吊) | 1 |
| 根(每个四张相同,含杠) | 每根 1 |
| 杠上花(自摸)/ 杠上炮(点炮) | 1 |
| 抢杠胡 | 1 |
| 海底捞月 / 海底炮 | 1 |
| 天胡(庄家第一手即胡) | 3 |

番数累加(七对与标准牌形二取其高)。

## 谁付分

- **点炮**:由点炮者一人付全额。
- **自摸**:其余仍在场的玩家每人各付一份(含自摸加底)。
- **一炮多响**:允许,每个胡牌者各自向点炮者结算。
- **血战到底**:胡牌者退出摸打、继续旁观,其余人继续,直到三人胡牌/炸胡或牌墙摸完。

## 杠分

| 类型 | 收取 |
|---|---|
| 明杠(点杠) | 点杠者一人付 1 |
| 补杠(碰后加杠) | 其余在场玩家各付 1 |
| 暗杠 | 其余在场玩家各付 2 |

杠后从牌墙补牌;补牌后胡为杠上花,他人打出的杠上牌被胡为杠上炮;补杠时他人可抢杠胡(抢杠者一人付,杠分不成立)。

## 操作优先级与响应窗口

- 某人打牌后开启响应窗口,**固定 3 秒**(`claimWindowMs = 3000`)。窗口始终满时长,不提供"过"按钮,也没有任何提示。
- 窗口结束时由服务器统一裁定,不依赖消息到达先后:**胡 > 杠 > 碰**。
- 多人同时胡:全部成立(一炮多响)。
- 无人响应则轮到下家摸牌。
- 不合法或过期的碰/杠请求被忽略:不改变状态、不扣分、不占用窗口。
- 同级冲突(例如两人都碰)按出牌者下家起的座位顺序,靠前者优先。

## 炸胡

- **判定**:玩家在牌局进行中(摸打阶段)提交"胡"时,服务器按规则快照检查。若不能胡,包括牌型不成、含缺门,以及**不在可胡时机**(不是自己摸牌后的回合、也没有他人刚打出的牌可胡;打牌者自己点胡也算),一律炸胡。
- 炸胡玩家公开手牌,视同胡牌:退出摸打、旁观,不能摸/打/碰/杠;牌局继续。
- **处罚**:共扣 8 分,由另外三人平分;8 不能被 3 整除,**余数 2 分给炸胡者下家起按座位顺序的前两人各多 1 分**,即 3 / 3 / 2(例:炸胡者座位 0 → 座位 1、2 得 3,座位 3 得 2)。
- 炸胡处罚**不受连庄倍数影响**。
- 炸胡与胡牌合计满三人时本局结束。
- 换牌/定缺阶段按"胡"请求无效(不算炸胡);摸打阶段按"胡"则可能炸胡。**界面上的"胡"按钮没有二次确认,摸打阶段误触会被罚 8 分。**

## 流局结算

牌墙摸完或三人胡牌/炸胡时结束:

- **查花猪**:牌墙摸完时,仍在场且手牌/副露中还有缺门花色者为花猪,向每位非花猪玩家(含已胡/炸胡者)赔 8 分。
- **查大叫**:未胡牌且未听牌者,向每位听牌者赔 `2^(听牌者最大可能番数)`(按底分计)。
- **退税**:花猪/未听牌者须退还本局已收的杠分。
- 已胡牌或炸胡的玩家不付查花猪/查大叫。查花猪、查大叫、退税、杠分、胡牌分均乘连庄倍数(炸胡除外)。流局查叫只在牌墙摸完时进行;三人已胡/炸胡结束时不查。

## 庄家与连庄

- 庄家本局胡牌**或炸胡**(视同胡牌):下一局连庄。
- 否则下庄,由下一座位玩家(座位+1)做庄。
- **连庄翻倍**:连庄 n 次,倍数 `min(2^n, 4)`,作用于所有分数**除炸胡处罚外**。

## 计分与累计

- 每人初始 0 分,允许负分;每局结束由服务器结算,累计总分保存在房间内。
- 每局每笔变动均写入公开结算记录;计分表可由玩家手动隐藏/显示,不影响牌局。

## 断线与解散

- 断线不会自动胡牌/炸胡,也不改变手牌和分数,可回到原座位。
- 四人全部离线超过 60 秒(大厅阶段 5 分钟)解散。
- 一局结束后等待下一局,连续 10 分钟无人进入下一局则解散;牌局进行中不按此计时。
- 解散后删除该桌数据,邀请链接与重连凭证失效。由 Durable Object alarm 执行。
